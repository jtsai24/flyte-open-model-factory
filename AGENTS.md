# Repository working agreements

## Public decision records

- Use public GitHub issues to capture decisions after they have been discussed and agreed with the user.
- Do not use issue creation as the mechanism for making or proposing a decision.
- Before creating an issue, discuss the decision with the user and present the proposed issue content for review.
- Create the issue only after the user explicitly approves both the decision and the issue wording.
- Do not create, edit, close, or otherwise modify a GitHub issue without the user's explicit approval for that action.
- Never include credentials, secrets, or other sensitive information in a public issue.
